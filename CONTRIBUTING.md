# Contributing

Thank you for your interest in contributing to SOC-Aid.

## How to Contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes.
4. Test the changes.
5. Commit the changes with a meaningful message.
6. Open a pull request.

## Suggested Areas

Contributors can help with:

- Additional alert types
- Improved correlation rules
- Better testing
- Documentation
- Threat-intelligence integrations
- CSV/JSON input support
- User interface improvements

## Commit Messages

Use clear commit messages such as:

- Add alert correlation tool
- Improve evidence safety
- Add malware test case
- Update installation documentation
- Fix invalid alert handling

## Security

Never commit API keys, passwords, credentials, or private security logs.
