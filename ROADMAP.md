# Roadmap

## v0.1.0 — Initial MVP

- Security alert parsing
- Alert correlation
- Rule-based risk assessment
- LLM-based evidence analysis
- Evidence-aware reasoning
- Human analyst recommendations
- Error handling
- Functional testing
- Evidence safety testing
- Professional triage report

## v0.2.0 — Expanded Alert Processing

- CSV security alert input
- JSON file input
- Larger alert datasets
- Improved correlation rules
- Time-window based correlation
- Multiple alert patterns

## v0.3.0 — Threat Intelligence Integration

- IP reputation lookup
- WHOIS information
- Threat intelligence APIs
- External indicator enrichment

## v0.4.0 — SOC Workflow Improvements

- Alert prioritization
- Analyst case tracking
- Investigation history
- Alert filtering
- Searchable incident records

## v0.5.0 — Production-Oriented Features

- SIEM integration
- Authentication
- Role-based access control
- Persistent storage
- Monitoring and logging
- Improved reliability

## Future Vision

SOC-Aid aims to become an evidence-aware AI assistant that reduces
repetitive alert-triage work while keeping human SOC analysts in control.
