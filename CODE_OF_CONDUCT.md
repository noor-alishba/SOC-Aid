# Code of Conduct

## Our Standards

Contributors are expected to:

- Be respectful.
- Communicate professionally.
- Provide constructive feedback.
- Welcome different perspectives.
- Focus discussions on improving the project.

## Unacceptable Behavior

The project does not tolerate:

- Harassment
- Personal attacks
- Discrimination
- Threats
- Malicious behavior

## Responsibility

Project maintainers may take appropriate action when community
standards are violated.
