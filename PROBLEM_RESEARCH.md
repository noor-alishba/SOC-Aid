# Problem Research

## Problem Statement

Security Operations Center (SOC) analysts are responsible for reviewing large numbers of security alerts and determining which events require immediate investigation.

A major challenge is that alerts often need to be correlated with related activity before their actual risk can be understood.

SOC-Aid addresses this problem by providing an AI-assisted alert triage workflow.

## Target Users

- SOC analysts
- Security operations teams
- Cybersecurity students and trainees
- Small organizations with limited security-analysis resources

## Proposed Opportunity

SOC-Aid combines:

- Alert parsing
- Alert correlation
- Rule-based risk scoring
- LLM reasoning
- Evidence-aware analysis
- Investigation recommendations

## Expected Impact

SOC-Aid aims to reduce repetitive alert-triage effort while keeping human analysts in control of security decisions.
